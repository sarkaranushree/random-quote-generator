# Random Quote Generator

## About the Project
A responsive website that displays a random quote and its author using a public API. It is built using HTML, CSS, and JavaScript.

## Features
- Displays a random quote when the page loads.
- Fetches a new quote when the button is clicked.
- Displays a loading message during API requests.
- Handles API and network errors.
- Responsive design for mobile phones and laptops.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Dumb APIs Random Quote API

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Ensure you have an internet connection.
4. Click "New Quote" to fetch another quote.

## Project Files
- index.html: Website structure.
- style.css: Styling and responsive layout.
- script.js: API requests, loading state, and error handling.
